# 學程規劃表 · 四年課表

一個純前端（單一 HTML 檔案，無需後端、無需安裝）的大學排課規劃工具。

## 功能

- 設定主修科系，並新增雙主修 / 輔系 / 學程等額外身份
- 新增每一堂應修課程（名稱、學分數、類別）
- 拖曳課程卡片到大一～大四、上/下學期共 8 格的課表中
- 點選課程卡片再點選目標學期格子，也可完成排課（適合觸控裝置）
- 即時顯示：應修學分、已排學分、尚需學分，以及依類別統計的學分明細

## 使用方式

### 線上開啟（GitHub Pages）

啟用 GitHub Pages 後，直接開啟：

```
https://<你的帳號>.github.io/<repo名稱>/
```

### 本機使用

下載 `index.html`，直接用瀏覽器開啟即可，不需安裝任何套件或伺服器。

## 技術

純 HTML / CSS / JavaScript（原生 Drag and Drop API），字型使用 Google Fonts（Source Serif 4、Inter、IBM Plex Mono）。所有資料僅保存在瀏覽器記憶體中，重新整理頁面會清空，如需保存規劃結果請自行截圖或之後可擴充匯出功能。
