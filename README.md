# 學程規劃表 · 四年課表

一個純前端（單一 HTML 檔案，無需後端、無需安裝、無需建置工具）的大學排課與畢業標準檢核工具。

預設內建 **國立清華大學動力機械工程學系 113 學年度課表**，並實作了該系畢業規定中的多項細節判定（物理五選二、專業學程門數、核心通識四向度、雙重認證學分缺口等）。

## 功能

### 課程規劃
- 設定主修科系，並新增雙主修 / 輔系 / 學程等額外身份，每個身份可個別設定所需最低學分
- 額外身份可隨時勾選啟用 / 停用，停用時不計入畢業學分但保留資料，方便比較不同的畢業組合
- 一鍵匯入動機系必修課表（校定必修、系定必修、物理五選二），可勾選要加入的課程
- 手動新增課程（名稱、學分數、類別）；類別為「通識」時會追問所屬向度
- 拖曳課程卡片至大一～大四、上/下學期共 8 格的課表；也可「點選卡片 → 點選目標格子」完成排課（適合觸控裝置）
- 課表中的課程按 ↩ 移回待排課程池，課程池中按 ✕ 才會真正刪除
- 左右兩欄各自獨立捲動，捲動課程池時右側課表不會跟著移動

### 畢業標準檢核
依 113 學年度課表規定（校定必修 30 ＋ 系定必修 64 ＋ 專業學程 15 ＋ 其餘選修 20 ＝ **129 學分**）逐項檢核：

- **各分項學分進度**：大學中文、英文、通識、系定必修、物理五選二、專業學程、其餘選修，皆附進度條
- **所有分項皆不設上限**，超修的學分全數認列，不會被丟棄
- **摺疊清單**：每一分項下可展開，查看實際計入該項學分的課程與各自的配置學分
- **核心通識四向度檢核**：四大向度須各修至少一門，逐一列出已修課程，未修的以紅字標示；核心＋一般通識學分合計須達 20 學分（兩個條件獨立判定）
- **物理五選二檢核**：除學分外，另判定是否已於五科中修滿 2 門
- **專業學程檢核**：選定學程後（電控 / 奈微米 / 能源 / 精密機械與智慧製造），依規定判定核心課程 3 門是否修齊（缺哪門會列出）、選修課程是否達 2 門、學程內總門數是否達 5 門
- **0 學分必修項目**：體育、操行的自行勾選追蹤

### 學分優先序遞補
一門課若同時符合多個類別，學分依 **物理五選二 → 專業學程 → 其餘選修** 的優先序配置：前一類別額滿後，剩餘學分自動遞補至下一類別。畢業標準面板會顯示「學分遞補配置」明細，列出每門課的學分實際分配到哪些類別。

### 雙重認證處理
依課表備註，**電磁學、工程光學、近代物理導論** 得雙重認證為系定必修及專業學程學分。這三門課的卡片上會出現「雙認」切換按鈕，啟用後：

- 學分同時認列進「物理五選二」與「專業學程」，兩邊進度條都會前進
- 面板會分開顯示 **認列學分合計** 與 **實際修得學分**（每門課只計一次）
- 並提示因雙重認證造成的畢業學分缺口，須依規定另修習本系開設之選修課補足

### 存檔
- **💾 匯出規劃**：將科系、額外身份、所有課程、排課結果、雙認設定與 0 學分項目打包成 JSON 檔下載（檔名含科系與日期）
- **📂 匯入規劃**：讀取先前匯出的檔案還原整份規劃，覆蓋前會先確認

> 資料僅保存在瀏覽器記憶體中，重新整理頁面會清空，請善用匯出功能存檔。

## 使用方式

### 線上開啟（GitHub Pages）

啟用 GitHub Pages 後，直接開啟：

```
https://<你的帳號>.github.io/<repo名稱>/
```

### 本機使用

下載 `index.html`，直接用瀏覽器開啟即可，不需安裝任何套件或伺服器。

## 使用建議

1. 於「基本資料」勾選 **主修動機系**，畢業標準即以 129 學分為基準展開
2. 選擇要修習的 **專業學程**，學程檢核才會啟動
3. 於「常用課表匯入」勾選並匯入必修課程（物理五選二記得只勾實際要修的 2 門）
4. 通識、其餘選修、專業學程的課程請自行以「新增課程」逐一加入，課名建議與課表一致
5. 若有雙主修 / 輔系 / 學程，於「基本資料」新增身份並填入所需學分
6. 拖曳課程至各學期，隨時查看畢業標準檢核結果
7. 排完記得 **匯出規劃** 存檔

## 注意事項

- 專業學程課程以 **課程名稱比對** 判定，課名需與課表一致（例如「控制系統一」而非「控制系統(一)」）才抓得到
- 課表上標註 `*` 的課程非每年開課，排課前請確認當年度是否開設
- 本工具僅供個人規劃參考，**實際畢業資格請以系辦公告與教務系統審查結果為準**
